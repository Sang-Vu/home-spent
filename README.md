# Expense Tracker

A lightweight, production-ready Expense Tracker application built with vanilla Vite and TypeScript. 

## Live Demo
Check out the live application here: [View Live Demo](https://sang-vu.github.io/home-spent/)

## Core Features
*   **Pure TypeScript:** Built using standard web technologies without external UI frameworks.
*   **Progressive Web App (PWA):** Can be installed and used as a standalone application on mobile devices.
*   **Mobile-First Design:** Specifically tailored and optimized for mobile screens.

## Important Note on UI Display
⚠️ **Mobile Only:** This project is designed exclusively for mobile viewports. If you are viewing this on a desktop or laptop, the layout may appear unbalanced. 

For the best experience on a computer, please:
1. Right-click and select **Inspect** (or press `F12`).
2. Click the **Toggle Device Toolbar** icon (Mobile icon).
3. Select a mobile device preset (e.g., iPhone, Pixel).

## How to Run Locally
Since this repository contains the pre-built production files (`dist`), you do not need to install dependencies or build the source code.

1. Clone or download this repository.
2. Serve the `dist` folder using any static local server (e.g., VS Code **Live Server** extension or Node's `serve` package).
